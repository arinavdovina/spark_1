# S.P.A.R.K. Conference — starter website

Стартовый пакет лендинга конференции S.P.A.R.K., 7 November 2026, Moscow.

## Файлы
- `index.html` — структура и контент лендинга
- `styles.css` — дизайн-система и адаптивная верстка
- `script.js` — мобильное меню
- `assets/spark-poster.jpg` — исходная афиша

## Палитра
