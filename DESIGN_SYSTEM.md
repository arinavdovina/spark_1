# S.P.A.R.K. — v0 design system

## Design Read
- Artifact: event conference landing page
- Audience: teachers, tutors, methodologists, educational bloggers and creators
- Visual language: premium editorial event poster + admission-ticket geometry + restrained nocturnal glow
- Mode: Redesign · Overhaul
- Visual variance: 8/10
- Motion intensity: 5/10
- Information density: 4/10
- Asset dependence: 6/10
- Brand fidelity: 9/10

## Positioning
- Narrative role: the hero is an event poster that became a living webpage; subsequent sections alternate between manifesto, programme and editorial feature moments.
- Viewing distance: laptop-first, with mobile as a first-class responsive state.
- Visual temperature: energized, premium, slightly theatrical; never SaaS/EdTech-template bright.
- Capacity check: the full S.P.A.R.K. wordmark, date, city, meaning and registration state must fit inside one 100svh hero.

## Tokens
- Primary: #070B28 midnight navy
- Secondary: #0B1238 / #121943
- Neutral: #FFF1D3 ivory, #F2DDB0 warm paper
- Accent: #D6AE67 muted gold, #EFD5A1 soft gold
- Heading/editorial: Cormorant Garamond
- UI/body: Manrope
- Spacing: 8px base grid with larger 24/40/64/96px section rhythm
- Radius: mostly sharp edges; no pill-card UI. Rounded shapes appear only as ticket notches.
- Shadows: nearly none; depth comes from contrast, borders and glow.
- Motion: 200–300ms UI transitions; slow 4–5s spark shimmer; cursor glow only in hero; reduced-motion support.

## Protected contracts
- S.P.A.R.K. name and five-word expansion
- 7 November 2026
- Moscow
- Existing section anchors: about, tracks, speakers, program, tickets, venue
- No invented speaker names, ticket prices or venue details
