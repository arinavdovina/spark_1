# S.P.A.R.K. Conference — redesign v0

This is the first viewable redesign draft after approving the new visual direction.

## What changed in v0
- Hero now occupies exactly one viewport (`100svh`).
- `S.P.A.R.K.` is shown as one unbroken wordmark and designed to fit at desktop and mobile widths.
- The poster is no longer competing with the hero; it becomes a real brand asset in the About section.
- The visual system now follows the poster: midnight navy, ivory paper, muted gold, ticket borders/notches, editorial serif type and sparse sparks.
- Repetitive card-grid rhythm was replaced with varied section compositions.
- Existing anchors and confirmed event facts were preserved.
- Speaker names, ticket prices and venue are intentionally left as placeholders.

## Files
- `index.html` — v0 page
- `styles.css` — complete v0 styling and responsive states
- `script.js` — mobile menu + subtle hero cursor glow
- `assets/spark-poster.jpg` — supplied poster
- `DESIGN_SYSTEM.md` — design decisions
- `brand-spec.md` — brand asset/tokens
