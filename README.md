# S.P.A.R.K. Conference — website build

Готовая статическая версия лендинга S.P.A.R.K. Conference, 7 November 2026, Moscow.

## Файлы
- `index.html` — структура и контент
- `styles.css` — дизайн и адаптив
- `script.js` — мобильное меню + раскрытие биографий спикеров
- `assets/spark-poster.jpg` — афиша конференции

## Что обновлено
- Первый экран адаптирован так, чтобы S.P.A.R.K. и афиша лучше помещались в пределах экрана на desktop.
- В секцию спикеров внесены 6 профилей с именами: Татьяна Еремеева, Мария Никитина, Татьяна Фанштейн, Арина Вдовина, Елена Паремская, Оксана Рябцева.
- Для двух биографий, в которых не было имени, добавлены аккуратные карточки «Имя уточняется», без выдумывания данных.
- Добавлены раскрывающиеся биографии, ссылки на соцсети там, где они были переданы, и адаптив под мобильные устройства.
- Темы выступлений не выдумывались: пока отображается «Тема выступления — скоро».

## Перед публикацией
1. Добавить фотографии спикеров и заменить монограммы.
2. Уточнить имена двух спикеров без подписи.
3. Добавить темы выступлений.
4. Заполнить точную площадку, билеты и ссылку на регистрацию.
5. Проверить Telegram/социальные ссылки организаторов.

Сайт не использует внешние библиотеки и может быть открыт локально двойным кликом по `index.html`.
